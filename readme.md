# Expense tracker V3

- This version uses SQLlite and SQLAlchemy
- The difference between V3 and the previous models is that V3 uses SQL to retrieve data 

# Steps

- Clone the project
- Create a virtual environment python3 -m venv <venv name>
- Activate the environment: source <venv name>/bin/activate
- Install dependencies pip install -r requirements.txt
- To run: fastapi run main.py --reload
